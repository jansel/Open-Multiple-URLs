# Open Multiple URLs Tab privacy policy — 2.1.0 draft

Draft for the next release. The submitted 2.0.0 package remains covered by [PRIVACY.md](../PRIVACY.md). Set an effective date and publish this policy at release time.

Open Multiple URLs Tab processes the text you type or paste locally in your browser. The developer does not collect, receive, sell, or share your text, URLs, browsing history, or personal information. The extension contains no analytics, advertising, tracking, or remote code.

## Local storage

All opening options and the selected tab group are saved in local extension storage within the current browser profile. Group information is used only to offer a destination for newly opened tabs.

**Preserve input**, enabled by default, saves input text locally so it can be restored when the workspace is reloaded or reopened. Turning this preference off clears the saved input while leaving the current editor available until it is reloaded or closed. **Clear** empties both the editor and its saved copy.

Separate devices and profiles keep separate settings and URL lists. If you explicitly allow the extension in incognito mode, Chrome extension storage is shared between normal and incognito use within that profile. Uninstalling removes local extension storage.

## Opening links

When you click **Open URLs**, your browser visits the destinations you requested. Those websites receive the normal information associated with a browser visit and have their own privacy policies. Lazy loading postpones supported visits until their tabs are selected. The extension does not send non-URL lines to a search provider.

The extension does not read unrelated web page content or monitor the clipboard; it handles only paste events in its own text field.

## Contact

Questions or issues can be reported through the [project's GitHub issues](https://github.com/jansel/Open-Multiple-URLs/issues). Information you voluntarily post there is handled by GitHub and is visible according to the repository's settings.
